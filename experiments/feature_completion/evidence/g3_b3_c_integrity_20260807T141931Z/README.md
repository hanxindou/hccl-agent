# G3-B3-C host integrity and bounded retry evidence

This evidence covers standard CRC32, deterministic corruption and sequence faults, logical-tick timeout, bounded retry, retry exhaustion, and explicit failure classes in the CPU_SIM/host path. It is not evidence of hardware CRC, NIC/HCCL retry, a real communicator, or a real network timeout. No ACL/HCCL runtime API was executed.
