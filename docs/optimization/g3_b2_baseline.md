# G3-B2 optimization baseline

The frozen baseline is the 18 performance and four reliability scenarios in `configs/optimization/g3_b2_benchmark_matrix.json`, using seed 20260804 and the immutable parameters in `experiments/optimization/g3_b2_parameter_freeze.json`. The baseline source and raw results remain in the G3-B2-A evidence directory; they were not regenerated or overwritten.

All latency, bandwidth, scale, reliability, and topology observations are `SIMULATED_ONLY`. The baseline is not real NPU performance, training acceleration, profiler evidence, or official HCCL runtime acceptance.
