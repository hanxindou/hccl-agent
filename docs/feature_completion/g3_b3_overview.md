# G3-B3 feature completion overview

G3-B3 adds lossless sparse index/value transport, host CRC32 integrity with logical timeout and bounded retry, bounded credit/backpressure modeling, Schedule IR v2 and Agent proposal v2 integration, and an isolated official ACL/HCCL compile/link-only source target.

CPU_SIM remains the default host-executed reference plugin. Simulator performance remains simulated only. The official runtime source target is default OFF and is never loaded or executed by acceptance commands.
